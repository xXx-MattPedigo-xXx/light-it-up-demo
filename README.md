# Light-It-Up Display Designer (demo)

**Try it:** https://xxx-mattpedigo-xxx.github.io/light-it-up-demo/

A clickable prototype of a website where customers design a Christmas light display on a photo of their house:

- Upload a house photo (or use the sample house) and set the scale from something you know the size of, like a garage door.
- Add props with two clicks: rooflines, continuous lines (click every corner), window outlines, arches, mega tree, matrix, wreath, star, bushes (string or matrix) and floodlights.
- See an itemized estimate per prop, untick any line item you don't need, and switch between professional installation and DIY.
- Turn the design into a parts list in the **DIY shop**.

> **Prototype.** Prices are examples. Nothing is saved to a server, sent or charged. Everything you do stays in your own browser.

The whole demo is one file, `index.html`, with no build step. It's published with GitHub Pages from the `main` branch.
